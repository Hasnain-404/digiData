[STEP 1] - Purane Cloud Data ka Backup & Local me Restore (One-time)
-------------------------------------------------------------------
Agar MongoDB Atlas cloud me purana trades data hai:
Option A: Agar saara data already Trading_Journal.xlsx me hai, toh kisi migration

Option B: Agar Atlas me extra data hai:

          - Local MongoDB (mongodb://127.0.0.1:27017/backtesting_dashboard) me import karein.

[STEP 2] - Backend .env File Update
-------------------------------------------------------------------
File path: backend/.env
Cloud Atlas URI ko local MongoDB URI se replace karein:

  # MONGO_URI=mongodb+srv://devxpert404:...@cluster0.ybz5p.mongodb.net/backtesting_dashboard

  # Ab (Offline Local):
  MONGO_URI=mongodb://127.0.0.1:27017/backtesting_dashboard

[STEP 3] - Frontend Icons & Fonts Offline Setup
-------------------------------------------------------------------
File path: frontend/src/main.jsx
- Aapke frontend package.json me 'remixicon' already installed hai.
- index.html se CDN link hata kar main.jsx me local import karein:
      import 'remixicon/fonts/remixicon.css';
- index.css se online @import Google Fonts hata kar local/system fonts use karein.

[STEP 4] - Testing Without Internet
-------------------------------------------------------------------
1. Computer ka Wi-Fi / Ethernet disconnect karein.
2. Backend start karein: cd backend && npm run dev
3. Watcher start karein: cd excel_sync && python watcher.py
4. Frontend start karein: cd frontend && npm run dev
5. Browser me http://localhost:5173 open karein.
   -> Pura dashboard bina internet ke smooth chalega!
